# docs — 送料くらべ

荷物の3辺（cm）と重さ（g）を入力すると、送れる発送方法だけを資材代込みの安い順に並べる単体 HTML ツールです。
ビルド不要で、ブラウザ（Safari / Chrome など）で `index.html` を開けばそのまま動きます。

```bash
open docs/index.html     # macOS
```

## 公開URL（GitHub Pages）

このフォルダはそのまま GitHub Pages で配信できます。リポジトリの
**Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `/docs`**
を選んで Save すると、下記URLで誰でもアクセスできるようになります。

```
https://penmawashi8-ux.github.io/Uranai/
```

## 対応している発送方法（20種）

| 区分 | 発送方法 |
|------|----------|
| 日本郵便 | ミニレター、定形郵便、定形外郵便（規格内 / 規格外）、ゆうメール、スマートレター、クリックポスト、レターパックライト / プラス、ゆうパケット |
| ゆうゆうメルカリ便 | ゆうパケットポスト（シール / 専用箱）、ゆうパケットポストmini、ゆうパケット、ゆうパケットプラス、ゆうパック |
| らくらくメルカリ便 | ネコポス、宅急便コンパクト、宅急便 |
| メルカリ | 梱包・発送たのメル便 |

## 機能

- 3辺を長い順に並べ替えて「最長辺・2番目の辺・厚さ・3辺合計」を自動計算し、宅配サイズ区分（60〜200サイズ）も表示
- 専用箱・シール・専用封筒の資材代を送料に合算して比較
- サイズオーバーで使えない方法は、その理由（例：`厚さ 4.0cm ＞ 3.0cm`）付きで別枠に表示
- 上限の92%以上を使っている場合は「ぎりぎり」を表示
- 「郵便・一般 / メルカリ便」の絞り込みと、追跡・匿名配送・ポスト投函・補償での絞り込み
- 宅急便は「サイズと重さの大きいほう」で料金を決定するヤマトのルールを反映
- **2026年10月1日の日本郵便 運賃改定**を「適用する料金」で切り替え可能

## 料金データの基準（2026年9月時点）

| 対象 | 基準 |
|------|------|
| 定形郵便・定形外郵便 | 2024年10月1日改定後（2026年10月の改定対象外） |
| ゆうメール | 2025年11月1日改定後（150g 190円 / 250g 230円 / 500g 320円 / 1kg 380円） |
| ネコポス | 2025年11月10日のサイズ拡大後（3辺合計60cm・長辺34cm・厚さ3cm） |
| クリックポスト・ゆうパケット | 現行と2026年10月1日改定後の両方を収録 |
| レターパック・スマートレター | 現行（2026年10月の改定対象外） |
| メルカリ便 | 全国一律料金。2026年10月時点での改定アナウンスなし |

距離で料金が変わる通常の宅急便・ゆうパック（メルカリ便以外）は対象外です。

### 2026年10月1日の改定内容

- クリックポスト: 185円 → **240円**。重量上限 1kg → **2kg**、サイズ規格が「3辺合計60cm・長辺34cm」に変更、差出はポスト投函のみ（窓口差出は廃止）
- ゆうパケット: 厚さ別料金（250 / 310 / 360円）を廃止し **一律360円**。サイズ規格が「3辺合計60cm・長辺34cm・ポスト投函可能」に変更
- 通常のゆうパックも平均約10%値上げ（本ツールの対象外）

## 料金データの更新

料金表は `index.html` 内の `METHODS` 配列に集約しています。改定時はここだけを直してください。

- `fit` … 通る条件（`maxLong` 最長辺 / `maxShort` 2番目の辺 / `maxThick` 厚さ / `maxSum` 3辺合計 / `minLong`, `minShort` 最小寸法）。専用箱が複数ある場合は配列に複数書くと、いずれか1つを満たせば「送れる」と判定します
- `fee` … `flat`（定額）/ `weight`（重さ別）/ `thickness`（厚さ別）/ `size`（3辺合計別）
- `material` … 専用箱・シールなどの資材代
- `REVISION_2026_10` … 改定後モードで上書きする内容。将来の改定もこの形で追加できます
