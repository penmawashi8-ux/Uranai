# tools

占い動画生成とは独立した補助ツールを置く場所です。

## shipping_calculator.html — 送料くらべ

荷物の3辺（cm）と重さ（g）を入力すると、送れる発送方法だけを資材代込みの安い順に並べる単体 HTML ツールです。
ビルド不要で、ブラウザ（Safari / Chrome など）でファイルを開けばそのまま動きます。

```bash
open tools/shipping_calculator.html     # macOS
```

### 対応している発送方法（20種）

| 区分 | 発送方法 |
|------|----------|
| 日本郵便 | ミニレター、定形郵便、定形外郵便（規格内 / 規格外）、ゆうメール、スマートレター、クリックポスト、レターパックライト / プラス、ゆうパケット |
| ゆうゆうメルカリ便 | ゆうパケットポスト（シール / 専用箱）、ゆうパケットポストmini、ゆうパケット、ゆうパケットプラス、ゆうパック |
| らくらくメルカリ便 | ネコポス、宅急便コンパクト、宅急便 |
| メルカリ | 梱包・発送たのメル便 |

### 機能

- 3辺を長い順に並べ替えて「最長辺・2番目の辺・厚さ・3辺合計」を自動計算し、宅配サイズ区分（60〜200サイズ）も表示
- 専用箱・シール・専用封筒の資材代を送料に合算して比較
- サイズオーバーで使えない方法は、その理由（例：`厚さ 4.0cm ＞ 3.0cm`）付きで別枠に表示
- 上限の92%以上を使っている場合は「ぎりぎり」を表示
- 「郵便・一般 / メルカリ便」の絞り込みと、追跡・匿名配送・ポスト投函・補償での絞り込み
- 宅急便は「サイズと重さの大きいほう」で料金を決定するヤマトのルールを反映

### 料金データの更新

料金表は `shipping_calculator.html` 内の `METHODS` 配列に集約しています。改定時はここだけを直してください。

- `fit` … 通る条件（`maxLong` 最長辺 / `maxShort` 2番目の辺 / `maxThick` 厚さ / `maxSum` 3辺合計 / `minLong`, `minShort` 最小寸法）。専用箱が複数ある場合は配列に複数書くと、いずれか1つを満たせば「送れる」と判定します
- `fee` … `flat`（定額）/ `weight`（重さ別）/ `thickness`（厚さ別）/ `size`（3辺合計別）
- `material` … 専用箱・シールなどの資材代

現在の金額は 2024年10月1日の郵便料金改定後のもの、およびメルカリ便の全国一律料金に基づいています。
距離で料金が変わる通常の宅急便・ゆうパック（メルカリ便以外）は対象外です。
